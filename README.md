# Retail Business Analytics Dashboard

An interactive 3-page Power BI dashboard analyzing retail sales, profit, customers and regional performance.

**Tools:** Power BI, DAX, Power Query, star-schema data modeling

## Key figures

- $12.64M in sales (+51.5% YoY)
- $1.47M in profit (+52.3% YoY)
- 25K orders and 1,590 customers

## What's inside

- **3 report pages** with KPI cards, slicers, and bar, column, line and donut charts
- **Page navigation** using buttons and bookmarks
- **Star-schema model** linking 4 tables: Sales, Product, Location, Customer
- **DAX measures** for time intelligence (YoY), plus dynamic Top-N rankings
- **Interactive slicers** to highlight top segments and regions

## How to open

1. Download `retail-business-analytics-dashboard.pbix`.
2. Open it in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free, Windows).
3. Use the slicers and page buttons to explore.
